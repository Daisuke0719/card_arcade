# ババ抜き（babanuki）

担当: 担当1 / Issue #1

## 遊び方

53枚（52枚 + 赤ジョーカー1枚）を4人（あなた + CPU 3人）に配り切ります。配った直後に、
各プレイヤーの手札から同じ数字のペアが自動で捨てられた状態でゲームが始まります。

自分の手番では、左隣のプレイヤーの裏向きの手札から1枚を選んでクリックし、1枚引きます。
引いたカードとペアがそろえば、その場で2枚とも捨てられます。手札が0枚になったプレイヤーは
その時点で上がりになり、以降は手番も引かれる対象にもなりません。

最後まで残った1人がジョーカーを持ったまま最下位になります。上がった順に1位から4位までの
順位が結果画面に表示されます。

## ルール

このリポジトリで採用したルールです。

- ジョーカーは赤1枚だけを使用します（黒のジョーカーは使いません）。
- ペアの条件は「同じランクが2枚」です。スート（マーク）と色は問いません。
- 同じランクが3枚あるときは、先頭の2枚だけ捨てて1枚を手札に残します。
- 同じランクが4枚あるときは、2ペアとも捨てて0枚にします。
- ジョーカーはどのカードともペアにならず、いずれかのプレイヤーの手札に残ります。
- 引く相手は左隣に固定です。自分で相手や方向を選ぶことはできません。
- 引く相手がすでに上がっていた場合は、その次に残っているプレイヤーから引きます。

今回は実装しないローカルルールは `docs/games/babanuki.md` に記載のとおりです
（ジョーカー2枚、色を揃える必要のあるペア、引く相手を自分で選ぶ、など）。

## 実装メモ

- `logic.ts` の `BabanukiState` は、手札（`hands`）と手番・上がった順（`turn: TurnState`）、
  進行段階（`phase`）を持ちます。`phase` は `"playing"`（入力待ち）→ `"revealing"`（引いた
  カードを見せている間）→ `"playing"` を繰り返し、生存者が1人になったら `"finished"` になります。
- ペア判定は `discardPairs` に集約しています。`partitionJokers` でジョーカーを分けたうえで
  `groupByRank` で同ランクをまとめ、2枚単位で捨てます。
- 「左隣から引く」「上がった人を飛ばす」は `@core` の `neighborId` / `finishPlayer` に任せています。
  自作の判定は書いていません。
- CPU がどの位置を引くかは `cpu.ts` の `chooseDrawIndex` に分けています。乱数は
  `createRng(state.seed + state.drawCount)` で作るため、`logic.ts` 側は `Math.random()` を
  使いません。
- CPU の手番の進行は `BabanukiGame.tsx` の `useCpuTurn(pendingDelayMs(state), ...)` の1行だけで、
  `.tsx` に `setTimeout` は書いていません。
- テストでは、ペア判定（2枚 / 3枚 / ジョーカー）、引いた直後の即時ペア処理、上がった人のスキップ、
  上がった順の順位付け、CPU の手番中に `draw` を送っても状態が変わらないことを確認しています。
