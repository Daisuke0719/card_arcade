# 神経衰弱（shinkeisuijaku）

担当: 担当3 / Issue #2

## 遊び方

1人用です。裏向きに並んだ16枚から2枚をめくり、8組すべてのペアをそろえます。

1. 裏向きのカードをクリックして1枚めくる。
2. もう1枚めくると判定に入り、800ms のあいだ入力を受け付けない。
3. 2枚のランクが同じならペア成立。表向きのまま場に残る。
4. 違うランクなら、2枚とも裏向きに戻る。
5. 8組そろうとクリア。結果に手数が表示される。

手数は2枚めくるごとに1増えます。「もう一度」を押すと配置を選び直し、手数は0に戻ります。

## ルール

`docs/games/shinkeisuijaku.md` に記載されたルールをそのまま実装しています。

- 52枚のうち、ランダムに選んだ8ランクから2枚ずつ、計16枚を使う。ジョーカーは使わない。
- 16枚をシャッフルし、4列 × 4行に裏向きで並べる。位置は左上から 0〜15。
- ペア判定はランクだけで行う。スートと色は関係しない（ハートの7とスペードの7はペア）。
- 1回にめくれるのは2枚まで。判定中のクリックは無視し、状態を変えない。
- ペアが成立したときも、しなかったときも同じだけ判定中になる。ペアだけ待ち時間を省く分岐は作らない。
- ペア成立済みのカード、めくったばかりのカード、盤面の範囲外は選べない。
- 手数は2枚めくった時点で1増える。1枚目だけでは増えない。

今回実装しないローカルルール:

- スートまで一致して初めてペアとする方式、同じ色だけ有効とする方式
- ペアを取ったら続けてもう一度めくれる連続めくり
- 2人以上の対戦、CPU 対戦
- 52枚すべてを並べる方式、ジョーカーを混ぜる方式
- 制限時間、開始時に全部を一瞬見せる演出、3枚めくり

## 実装メモ

### 状態の持ち方

`logic.ts` の `ShinkeisuijakuState` が盤面（`board`）、めくり中の位置（`flipped`）、ペア成立済みの位置（`matched`）、`phase`、`moves`、`seed` を持ちます。カード自体は動かさず、位置の集合だけで表と裏を表しています。

`phase` は `idle` / `one-flipped` / `judging` の3つです。終了は `phase` ではなく `matched.length` で判定するため、`isGameOver` は8組そろったかどうかだけを見ます。

### 判定の中心になっている関数

- `canFlip(state, index)`: 選べるかどうかの判定を1か所にまとめています。判定中、範囲外、ペア成立済み、めくり済みのいずれかなら `false` です。`flipCard` はこれが `false` のとき `state` をそのまま返すため、連打しても状態が変わりません。画面の `disabled` に頼らず `logic.ts` で弾いています。
- `resolveFlip(state)`: `sameRank` で2枚を比べ、成立なら位置を `matched` へ移し、不成立なら `flipped` を空にするだけです。

### 時間の扱い

`pendingDelayMs` は判定中に `REVEAL_DELAY_MS`（800）を返し、それ以外は `null` を返します。`ShinkeisuijakuGame.tsx` の `useCpuTurn(pendingDelayMs(state), () => dispatch({ type: "tick" }))` がこの値だけを見てタイマーを動かすため、`logic.ts` には時間が出てきません。テストは `reduce(state, { type: "tick" })` を呼ぶだけで判定を進められます。

### 乱数

`createInitialState(seed)` が `createRng(seed)` を作り、ランクの選択と16枚の並べ替えの両方に同じ乱数を使います。seed を固定すれば毎回同じ配置になります。画面側は起動時と「もう一度」のたびに新しい seed を渡します。

### テストで守っていること

`logic.test.ts` には仕様書の必須テスト7件に加えて、同じ seed で同じ配置になること、リセットで盤面と手数が初期化されることを書いています。無効な操作（判定中の3枚目、ペア成立済みの再クリック、同じ場所の2回クリック、範囲外の位置）は、状態が変化しないことをオブジェクトの同一性で確認しています。
