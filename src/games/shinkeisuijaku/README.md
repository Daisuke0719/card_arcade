# 神経衰弱（shinkeisuijaku）

裏向きに並んだ16枚を2枚ずつめくり、同じ数字のペアをすべてそろえる1人用ゲームです。何手でそろえられたかが成績になります。

## 遊び方

1. 場には8組16枚が、4列×4行の裏向きで並びます。
2. 裏向きのカードをクリックして、2枚めくります。
3. 2枚の数字が同じならペア成立で、そのまま表向きで場に残ります。
4. 数字が違うと、800ミリ秒後に2枚とも裏向きに戻ります。
5. 8組すべてそろうとクリアです。手数の少なさを目指します。
6. 「もう一度」を押すと、配置し直して最初からやり直せます。

## ルール

- ペア判定は**数字（ランク）だけ**で行います。スートや色は関係ありません（ハートの7とスペードの7はペアです）。
- 1回にめくれるのは2枚までです。2枚めくると判定中になり、その間のクリックは無視します（3枚目はめくれません）。
- ペアが成立してもしなくても、同じ800ミリ秒だけ判定中になります。ペアのときだけ待ち時間を省く分岐は作っていません。
- すでにペアで表向きのカードと、いまめくったばかりのカード（同じ場所の2回目のクリック）は選べません。
- 手数は2枚めくった時点で1増えます。1枚目をめくっただけでは増えません。

`docs/games/shinkeisuijaku.md` の「今回は実装しないルール」に挙がっているもの（スート一致・連続めくり・CPU 対戦・タイムアタックなど）は実装していません。

## 実装メモ

- ルールは `logic.ts` に純粋関数として置き、`react`・乱数・時間を持ち込んでいません。乱数は引数の `Rng` で受け取り、テストでは `createRng(seed)` を渡します。
- 待ち時間は `pendingDelayMs(state)` に集約し、画面側は `useCpuTurn(pendingDelayMs(state), () => dispatch({ type: "tick" }))` の1行だけで扱います。判定中の解決はテストからは `reduce(state, { type: "tick" })` で呼び、`setTimeout` はテストしません。
- 状態は `board`（16枚）、`flipped`（めくり中の位置）、`matched`（ペア成立済みの位置）、`phase`、`moves`、`seed` で持ちます。表向きかどうかは `isFaceUp(state, index)` が `flipped` と `matched` から判定します。
- 盤面は表向きと裏向きが混在するため、`Hand` ではなく `Card` を16個並べ、CSS Modules の `grid-template-columns: repeat(4, max-content)` で4列にしています。
