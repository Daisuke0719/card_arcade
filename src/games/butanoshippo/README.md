# ぶたのしっぽ

プレイヤー1人と CPU 3人で遊ぶ、52枚のターン制ぶたのしっぽです。

## 遊び方

カードは伏せた輪として表示されます。手番の人は光っている先頭のカードを1枚めくり、場の中央に積みます。直前のカードと同じ数字が続いたら、その時点の手番の人が場札をすべて引き取ります。引き取り後は次の人の手番です。

輪のカードがなくなったら終了し、引き取った枚数が少ない順に順位が決まります。場に最後まで残ったカードは数えません。

## ルール

- 同じランクが続いたときだけ場札を引き取り、引き取り枚数の少ない順に順位を決めます。
- 輪の最後のカードも通常どおり判定し、最後に場へ残ったカードは数えません。

## オンライン対戦

2〜4人で遊べます。CPU は参加せず、全員が人間のプレイヤーです。ルールと勝敗はサーバー側で判定し、画面には公開してよい情報だけが届きます。伏せたカードのランクとスートは、めくられるまで公開状態に含まれません。

引き取りが起きたときは、`onlineAdapter` の `pendingDelayMs` と `tick` が一致した札を見せてから引き取ります。CPU 版と同じ `ButanoshippoBoard` を使うため、盤面の見た目は変わりません。

## 実装メモ

- オンライン用のルール検証と公開状態は `onlineAdapter.ts`、画面は `ButanoshippoOnlineView.tsx` にあります。

- 状態遷移とルールは `logic.ts` に集約しています。
- CPU と引き取り演出の待ち時間は `pendingDelayMs` で管理し、画面では共通の `useCpuTurn` を使います。
- 輪の裏向きカードは `Card` の `face="down"` で表示します。
