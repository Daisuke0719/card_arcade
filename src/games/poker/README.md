# ポーカー

## 遊び方

1. 52枚の山札からあなたとCPUに5枚ずつ配ります。
2. 交換したいカードをクリックして選び、「交換する」を押します。0枚交換もできます。
3. CPUも同時に一度だけ交換し、交換後に役の強さで勝敗を決めます。

## ルール

- ファイブカードドロー、2人固定、チップや賭けなしです。
- ハイカードからストレートフラッシュまで9種類を判定します。
- Aは通常14として扱い、A-2-3-4-5のストレートだけAを1として扱います。
- 同じ役は仕様で定めた `tiebreak` を比較し、すべて同じなら引き分けです。キッカーは比較しません。
- CPUはペア以上の組を残し、それ以外を捨てます。役がなければ強い2枚を残します。
- 捨てたカードは山札へ戻しません。交換後にCPUの手札を公開します。

## 実装メモ

`logic.ts` に役判定、比較、初期化、交換と状態遷移をまとめています。交換後は短い showdown 表示を挟み、`useCpuTurn` の tick で結果画面へ移ります。CPUの交換判断は乱数を使わない `chooseDiscardIds` です。
