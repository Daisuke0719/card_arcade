# 七並べ（shichinarabe）

担当: 担当7 / Issue #4

## 遊び方

1. ゲームを開くと、52枚が4人（あなた + CPU 3人）に配られ、4枚の7が自動で場に置かれます。
2. ダイヤの7を持っていた人が先手になり、以降は「あなた → CPU 1 → CPU 2 → CPU 3」の順で手番が進みます。
3. 自分の手番では、緑枠で表示された(場のカードと同じスートで±1の)手札をクリックして1枚置きます。
4. 置けるカードが1枚もないときだけ「パス」ボタンが表示されます。パスは1人3回までです。
5. CPU の手番は自動で進みます。手札を先に出し切った人から順位が付き、全員終了すると結果画面が出ます。

## ルール

このゲームで**採用したルール**は次のとおりです（`docs/games/shichinarabe.md` に準拠）。

- 52枚を4人に13枚ずつ配り切り、配り終わった直後に4枚の7(スペード・ハート・ダイヤ・クラブ)を自動で場に置く。
- ランクは A=1 から K=13 の直線として扱う。Aの下・Kの上には置けず、AとKはつながらない。
- 1手番で置けるのは1枚だけ。置けるカードが1枚でもあるときはパスできない。
- パスは1人3回まで。4回目のパスで脱落し、手札を全部(場とつながっていないカードも含めて)場に置いて手番から外れる。
- 手札を出し切った人から順に上位。終了時に残っていた最後の1人はその次、脱落した人は脱落が遅い人ほど上位になる。

今回は実装しなかったローカルルール(都落ち、A と K が繋がる循環ルール、パス回数の変更など)は、`docs/games/shichinarabe.md` の「今回は実装しないルール」のとおり不採用です。

## 実装メモ

- 状態は `ShichinarabeState`(`logic.ts`)で持つ。場は `Board`(`Record<Suit, boolean[]>`、index 0..12 が A..K)、手番と上がり順は `@core` の `TurnState` をそのまま使う。
- 判定の中心は `canPlace(board, card)`。場のカードの±1だけを許可し、盤面の端(index 0 / 12)を超えないことで A・K の境界とワードアラウンド禁止を両方満たす。
- `place` / `passTurn` / `dropOut` はいずれも「今の手番のプレイヤーか」を先頭でガードし、そうでなければ state をそのまま返す。
- CPU の手番は `pendingDelayMs` が `CPU_DELAY_MS` を返し、`useCpuTurn` の1行だけで進む。`.tsx` に `setTimeout` は書いていない。CPU の候補選びは `cpu.ts` の `chooseCard`(乱数を引数で受け取る純粋関数)に分離した。
- テストは `logic.test.ts` にまとめ、`canPlace` の境界値・パス3回後の脱落・順位付けなど、Issue の必須テスト6件を含む。
