# ページワン（pageone）

担当: 担当9 / Issue #10

場に出ている1枚に対して、同じマークか同じ数字のカードを重ねていき、
手札を先に0枚にした人が勝ちの4人対戦です（あなた + CPU 3人）。

## 遊び方

1. 場札の一番上と、同じマークか同じ数字のカードをクリックして出します。
   出せないカードは暗くなっていて押せません。
2. 出せるカードが1枚でもあるときは、必ず出します。山札は引けません。
3. 出せるカードが1枚も無いときだけ、山札をクリックして1枚引きます。
   引いたカードがそのまま出せるときは、その場で自動的に場に出ます。
4. 8 を出すと次の人が1回飛ばされ、A を出すともう1枚出せます。
5. 手札が0枚になった人が出た時点で終了です。2位以下は残り枚数の少ない順に並びます。

CPU 3人は 800ms ごとに1手ずつ自動で進みます。

## ルール

トランプゲームは家庭ごとにルールが違うため、`docs/games/pageone.md` を正典として
**次のルールで固定**しています。

### 採用したルール

- 52枚（ジョーカー無し）を4人に5枚ずつ配り、残りから1枚めくって場札にする（山札31枚）
- 出せるのは、場札の一番上と同じマークか同じ数字のカードだけ
- 出せるカードが1枚でもあるときは引けない。出せるカードが0枚のときだけ引ける
- 引いたカードが出せるときは、その場で出す（手札に残す選択はない）
- **8** … 次の人を1回飛ばす　/　**A** … もう1枚出せる（同じ人の手番が続く）
- A は出せる限り何枚でも続く。A の後に出せるカードが無ければ、通常どおり山札を引く
- 最後の1枚が 8 や A でも、効果より上がりが優先される
- 最初にめくった場札が 8 や A でも効果は発動しない（誰も出していないため）
- 山札が尽きたら、場札の一番上1枚を残して残りを混ぜ、山札に戻してから引く
- 場札が1枚しか無く山札も空のときは、何もせず手番を次の人へ渡す
- 1人が上がった時点で終了。2位以下は手札の枚数が少ない順（同数は同順位）

### 今回は実装しないローカルルール

「このルールが無い」という指摘を防ぐため、意図的に外したものを書いておきます。

| ローカルルール | 扱い |
|---|---|
| リバース（手番の向きが反転する） | 不採用。`reverseDirection` は使わない |
| ドロー2 / ドロー4 | 不採用 |
| ワイルドカード / 出したあとのマーク宣言 | 不採用 |
| 残り1枚のときの宣言義務 | 不採用 |
| 8 と A 以外の特殊カード（J スキップなど） | 不採用。特殊は2枚だけ |
| ジョーカーを入れる | 不採用。52枚のみ |
| 引いたカードを出さずに手札へ残す | 不採用 |
| 同じ数字を複数枚まとめて出す | 不採用。1手番に1枚（A で続けて出す場合を除く） |
| 全員が上がるまで続けて1位から4位まで決める | 不採用。1人上がった時点で終了 |
| 山札が尽きたらゲーム終了にする | 不採用。混ぜ直して続ける |
| 得点計算・複数回戦 | 不採用。1回で完結 |

## 実装メモ

### 状態の持ち方

状態は `logic.ts` の `PageOneState` 1つにまとめ、`reduce(state, action)` だけで進めます。
フェーズは2つしかありません。待ち時間はフェーズではなく `pendingDelayMs` が表します。

```text
playing ──(play / draw / tick)──> playing
   │
   │ 誰かの手札が0枚になった（applyPlay の中で判定）
   ▼
finished ──(reset)──> playing
```

手番は自作せず `@core` の `TurnState` に持たせ、`nextTurn` で進めます。

### 判定の中心になっている関数

**特殊カードを「手番の進み方」で表しているのが、このゲームの要です。**

`applyPlay` の中に `if (rank === "8") ... else if (rank === "A") ...` を積み上げると、
特殊カードが増えるたびに分岐が増え、片方を直すともう片方が壊れます。
そうではなく、8 も A も「手番を何人分進めるか」の違いとして扱っています。

| 出したカード | `stepsOf` | 見え方 |
|---|---|---|
| 8 | 2 | 次の人が飛ばされる |
| A | 0 | 同じ人がもう1枚出せる |
| それ以外 | 1 | 普通に次の人へ |

そのため `applyPlay` は「カードを場に置く → `advanceTurn(state, stepsOf(card))`」に収まり、
特殊カードの知識は `stepsOf` の3行だけに閉じています。

判定の入口は次の3つです。**画面の `disabled` には頼らず、すべて `reduce` の中で弾いています**
（連打やタイミングですり抜けないようにするため）。

| 関数 | 弾いているもの |
|---|---|
| `canPlay` | 場札とマークも数字も違うカード |
| `applyPlay` | 手番でない人 / 手札に無いカード / 出せないカード / 終了後 |
| `drawFromDeck` | 出せるカードが1枚でもあるときの「引く」（引き逃げ） |

### 時間と乱数の閉じ込め方

- **時間**: `logic.ts` に `setTimeout` は書きません。`pendingDelayMs` が
  「終了なら `null` / CPU の手番なら 800 / あなたの手番なら `null`」を返すだけで、
  実際に待つのは `PageOneGame.tsx` の `useCpuTurn` 1行です。
- **乱数**: `logic.ts` の中では `createRng(state.seed + state.drawCount + state.log.length)` の
  ように**状態から決まる seed** で作ります。`Math.random()` を呼ぶのは画面側の初期 seed だけです。

CPU の判断は `cpu.ts` の `chooseCard(moves, rng)` に分けています（出せる候補からランダムに1枚）。

### テストで守っていること

`logic.test.ts` に21件あります。正常系だけでなく、壊れやすいところを見ています。

- **必須テスト7件**（`canPlay` の3件 / 引く / 8 / A / 上がり）
- **やってはいけない操作**: 出せるのに引く / 手番でないのに出す / 終了後の操作
- **境界（山札0枚）**: 混ぜ直しで場札の一番上だけが残る / 山札も場札の残りも無いとき
- **境界（最後の1枚）**: 最後の1枚が 8 でも効果より上がりが優先される
- **不変条件**: 山札 + 場札 + 全員の手札が、決着まで常に52枚のまま
- **決定性**: 同じ seed なら同じ配りになる

「山札 + 場札 + 全員の手札 = 52枚」のテストは、実際に1ゲームを決着まで進めながら
毎手チェックしています。カードの増殖・消失と、進行が止まる不具合の両方をここで拾えます。
