# ページワン（pageone）

担当: 担当9 / Issue #10

## 遊び方

4人（あなた + CPU 3人）で対戦します。52枚をよく混ぜて5枚ずつ配り、残りの山札から1枚めくったものが最初の場札です。手番はあなたから始まり、画面の並び順（あなた → CPU 1 → CPU 2 → CPU 3）で進みます。

自分の手番になると、場札に出せるカードだけが押せる状態になります。カードをクリックすると場札に重なり、次の人へ手番が移ります。出せるカードが1枚も無いときは山札か「山札から引く」ボタンが押せるようになるので、そこから1枚引きます。引いたカードが場札に出せる場合は、手札に入らずそのまま場に出ます。

先に手札を0枚にした人が出た時点でゲームが終わり、順位が表示されます。「もう一度」を押すと新しい配りで再開します。

## ルール

このゲームで採用したルールです。

- 出せるのは、場札の一番上と同じマークか、同じ数字のカードだけです。
- 出せるカードが1枚でもあるときは、山札から引けません。出せないときだけ引きます。
- 引いたカードが出せるときは、その場で必ず出します。手札に残す選択はできません。
- 8 を出すと、次の人の手番を1回飛ばします。
- A を出すと、同じ人がもう1枚出せます。出せる限り何枚でも続けられます。
- 手札の最後の1枚が 8 や A でも、0枚になった時点で終了し、特殊効果は働きません。最初にめくった場札が 8 や A の場合も同じです。
- 山札が尽きたときは、場札の一番上だけを残して残りを混ぜ、山札に戻してから引きます。場札が1枚しか無く山札も作れないときは、引かずに手番を次の人へ移します。
- 先に手札を0枚にした人が1位で、その時点で終了します。2位以下は手札の枚数が少ない順で、同じ枚数なら同順位です。

今回は実装していないローカルルールです。

- リバース、ドロー2 / ドロー4、ワイルドカード、出したあとのマーク指定
- 残り1枚のときの宣言義務、8 と A 以外の特殊カード、ジョーカー
- 同じ数字をまとめて出すこと、全員が上がるまで続けること、得点計算や複数回戦

## 実装メモ

### 状態とルール

ルールは `logic.ts` の純粋関数だけで表しています。状態は山札 `deck`、場札 `field`（末尾が一番上）、プレイヤーIDごとの手札 `hands`、手番 `turn`（`@core` の `TurnState`）、`phase` / `winnerId` / `log` / `drawCount` / `seed` です。画面からの操作は `reduce(state, action)` を通り、`play` / `draw` / `tick` / `reset` の4種類だけを受け付けます。

### 判定の中心

出せるかどうかは `canPlay(card, field)` の `sameSuit(card, field) || sameRank(card, field)` に集約し、手札から出せるカードを取り出す `legalMoves` も同じ関数を使います。画面の `disabledIds`、山札を引けるかどうかの判定、CPU の候補選びが、すべてこの1つの判定を共有しています。

### 8 と A は手番の進み方で表す

特殊カードごとに `applyPlay` の中で分岐させると、カードが増えるたびに条件が積み上がります。そこで「出したあと手番を何人分進めるか」という値の違いとして `stepsOf` にまとめました。8 は2（次の人を飛ばす）、A は0（同じ人が続ける）、それ以外は1です。`applyPlay` は「場に置く → `advanceTurn(state, stepsOf(card))`」の順で進むだけになり、`advanceTurn` は `nextTurn` を指定回数だけ呼びます。

山札から引いたカードをその場で出す場合も同じ経路を通るため、引いた 8 や A も出したときと同じ効果になります。

### 時間と乱数

`pendingDelayMs` は、終了後とプレイヤーの手番では `null`、CPU の手番では `CPU_DELAY_MS`（800ms）を返します。画面側は `useCpuTurn(pendingDelayMs(state), () => dispatch({ type: "tick" }))` の1行だけで、`setTimeout` は書いていません。

`logic.ts` では `Math.random()` を使わず、山札の混ぜ直しは `createRng(state.seed + state.drawCount)`、CPU の選択は `createRng(state.seed + state.drawCount + state.field.length)` のように状態から決まる乱数を作ります。同じ seed なら同じ展開になるため、テストが安定します。

### CPU

`cpu.ts` の `chooseCard(moves, rng)` は、出せる候補から1枚を無作為に選び、候補が無ければ `null`（＝山札を引く）を返します。温存や優先の判断は入れていません。

### テストで守っていること

`logic.test.ts` では、必須テスト7件に加えて次を確認しています。

- 出せるカードがあるときの `draw` が無視される
- 手番でないときの `play` が無視される
- 引いたカードが出せるときは手札が増えない
- 山札が尽きたら場札の一番上だけが残り、残りが山札になる
- 進行中はいつでも山札 + 場札 + 全員の手札が52枚のままである
