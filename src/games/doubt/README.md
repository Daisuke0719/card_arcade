# ダウト

## 遊び方

4人（プレイヤー1人、CPU3人）で52枚を13枚ずつ配って遊びます。宣言ランクはAから始まり、ダウトが起きなければ次のランクへ進みます。

手番では手札から1〜4枚を選び、宣言ランクのカードとして裏向きで場に出します。実際のランクは自由です。出した人の左隣から順にダウトするか決め、最初にダウトした人がいれば直前の組だけを公開します。

宣言と違うカードが含まれていれば出した人が、すべて一致していればダウトした人が場札を全部引き取ります。引き取り後は場札を空にし、宣言をAへ戻して引き取った人の次から再開します。手札が0枚になった人から上がり、最後に残った人が最下位です。

## ルール

- 1〜4枚を同じ宣言ランクとして出し、ダウトの成否で場札の引き取り手を決めます。
- 手札を出し切った順に順位を付け、最後まで残ったプレイヤーが最下位です。

## オンライン対戦

2〜4人の参加者だけで遊び、CPU は参加しません。52枚を参加人数で配り切り、ルーム作成者から始めます。宣言ランクの進め方、ダウトの判断順、引き取り、上がりの判定は CPU対戦と同じです。

場に出したカードは、ダウトで公開されるまで枚数と宣言ランクだけを公開します。他のプレイヤーの手札は枚数だけを公開します。

## 実装メモ

- ルールとCPU判断は時間やReactから独立させ、時間待ちは `pendingDelayMs` と `useCpuTurn` で扱います。
- CPUは宣言ランクの所持数、出された枚数、場札の枚数を使ってダウトを判断します。
- 公開状態（`DoubtView`）には自分の手札と対戦相手の枚数だけを含めます。画面も `Hand variant="hidden"` で相手の実カードをDOMへ出しません。
- CPU対戦とオンライン対戦は同じ `DoubtScreen` を使います。CPU対戦はローカルの状態を `toPublicState` で公開状態にしてから渡し、オンライン対戦はサーバーから届いた公開状態をそのまま渡します。
- `onlineAdapter.ts` は `logic.ts` のルールを再利用し、Action の検証と、ダウト結果を表示したあとの進行（`pendingDelayMs` と `tick`）だけを追加しています。
