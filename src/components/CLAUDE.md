# 停止: ここは運営管理の領域です

`src/components/` は6チーム全員が使う共通の画面部品です。**変更しないでください。**

ここを1行変えると、6チーム全員のゲームとテストに影響します。
研修中にこのフォルダが変わると、他のチームの Pull Request が突然壊れます。

## やってよいこと

- 読むこと（実装を確認する、使える関数を探す）
- `src/components/index.ts` を見て「どんな部品があるか」を把握すること

## やってはいけないこと

- ファイルの追加・編集・削除
- リダイレクト（`>` `>>`）、`sed -i`、`cp`、`mv` などコマンド経由での書き換え
- 「ゲーム側から使いやすくするため」という理由での小さな修正

これらはフックが止め、コミット時と Pull Request でも検出されます。**迂回策を探さないでください。**

## 必要な機能が無いと思ったとき

自分で追加せず、次の形で人間に報告してください。

```
共通基盤への変更が必要かもしれません。

- やりたいこと:
- 足りないと思うもの:
- ゲーム側だけで実現する案（あれば）:
- 影響しそうな範囲:

講師に確認してください。
```

多くの場合、`@ui` の既存の関数を組み合わせれば実現できます。
先に `src/components/index.ts` の公開一覧と、`Card` / `Hand` / `DeckPile` の props を読み直してください。
