操作担当（Driver）を交代します。次の人がすぐ続けられるように、状況を10行程度でまとめてください。

現在の状態を確認してから書いてください。

```
git branch --show-current
git status --short
npm run scope
```

## 引き継ぎメモの形

```
## 今どこ
- 担当: <チーム> / <ゲーム名>
- ブランチ: feature/<ゲームID>
- Issue の Step: <1/2/3 のどこまで終わったか>

## 直前にやったこと
- <3行以内>

## 今できていること / できていないこと
- できている: <箇条書き>
- できていない: <箇条書き>

## 次の一手
- <次の人が最初にやるコマンドまたは作業を1つだけ>

## 注意
- <ハマっている点、判断待ちの点があれば>
```

最後に、次の Driver に向けて**最初に打つコマンドを1つ**だけ示してください。
迷わせないことが目的なので、選択肢を並べないでください。
